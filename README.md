# Roovia

Roovia is a hotel booking backend built with Spring Boot. It provides REST APIs for user authentication, hotel and room management, availability, bookings, guests, and payment processing through Stripe.

## Tech Stack

* Java
* Spring Boot
* Spring Security
* Spring Data JPA / Hibernate
* PostgreSQL
* JWT
* Stripe
* OpenAPI / Swagger
* Maven

## Features

* JWT-based authentication and authorization
* User profile management
* Hotel and room management
* Room inventory and availability management
* Guest management
* Booking management
* Stripe payment integration
* Stripe webhook handling
* RESTful API architecture
* OpenAPI API documentation

## Architecture

The application follows a layered architecture:

```text
Controller
    ↓
Service
    ↓
Repository
    ↓
Database
```

DTOs are used for API request and response models, while entities are kept within the persistence layer.

## Configuration

Create the required environment variables before running the application.

```text
DATABASE_URL
DATABASE_USERNAME
DATABASE_PASSWORD
JWT_SECRET_KEY
STRIPE_SECRET_KEY
STRIPE_WEBHOOK_SECRET
FRONTEND_URL
```

Sensitive credentials should not be committed to the repository.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/<username>/roovia.git
cd roovia
```

Run the application:

```bash
./mvnw spring-boot:run
```

On Windows:

```bash
mvnw.cmd spring-boot:run
```

The application will start on the configured server port.

## Stripe Webhooks

For local development, Stripe CLI can be used to forward webhook events to the application:

```bash
stripe listen --forward-to localhost:<port>/<webhook-endpoint>
```

The webhook signing secret generated by Stripe CLI should be configured as `STRIPE_WEBHOOK_SECRET`.

## API Documentation

When the application is running, the API can be explored through Swagger UI:

```text
http://localhost:<port>/swagger-ui/index.html
```
